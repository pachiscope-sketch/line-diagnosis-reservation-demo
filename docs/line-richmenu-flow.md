# リッチメニューからLIFFへの導線

`/line-flow` では、LINE公式アカウントのリッチメニューからLIFFアプリへ遷移する流れを、非エンジニアにも伝わる形で図解しています。

## 流れ

1. ユーザーがLINE公式アカウントを友だち追加
2. あいさつメッセージで診断やクーポンを案内
3. リッチメニューの「診断する」をタップ
4. LIFFアプリがLINE内で起動
5. 診断フォームを回答
6. 結果に応じて予約、会員証、クーポンへ誘導
7. 管理者にSlack通知
8. Supabase管理画面で回答、予約、会員情報を確認

## 発注者への説明

リッチメニューは、LINE公式アカウントの下部に常に表示できるメニューです。

ここに「診断する」「予約する」「会員証」「クーポン」などを配置し、タップ先にLIFF URLを設定します。

LIFFアプリでは、LINE User IDを取得できるため、診断回答、予約、会員証、ポイント情報を同じユーザーにひもづけられます。

`/line-links` では、リッチメニューやLIFF Endpoint URLに設定する候補URLを一覧で確認できます。

6分割リッチメニューの文言、リンク先、デザイン方針は `docs/rich-menu-design.md` にまとめています。

## 実案件での注意点

- LIFF Endpoint URLはHTTPSが必要
- LINE DevelopersでLIFFアプリを作成する
- リッチメニューのリンク先にLIFF URLを設定する
- 個人情報やUser IDの利用目的を明確にする
- Messaging APIを使う場合はWebhook設計も必要
