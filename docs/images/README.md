# スクリーンショット撮影手順

GitHub README冒頭に表示するためのスクリーンショット配置場所です。

現在、PNGスクリーンショットは未配置です。`top.svg`、`member-card.svg`、`admin.svg`、`line-flow.svg` はプレースホルダーとして入っています。

## 配置するファイル

| ファイル | 撮影する画面 | 推奨URL |
| --- | --- | --- |
| `top.png` | 診断トップ | `/` |
| `result.png` | 診断結果 | 診断回答後の結果画面 |
| `member-card.png` | QR会員証 | `/member-card` |
| `staff.png` | スタッフ来店処理 | `/staff` |
| `admin.png` | 管理画面 | `/admin` |
| `line-flow.png` | LINE導線説明 | `/line-flow` |

## 撮影手順

1. ローカルで `npm run dev` を実行、またはVercelデモURLを開く
2. Chrome DevToolsでスマホ幅を選択
3. ユーザー向け画面は `390 x 844` 付近で撮影
4. 管理画面はPC幅、または `1280 x 900` 付近で撮影
5. 個人情報に見える値はデモ用の名前、メール、相談内容にする
6. ファイル名を上記表に合わせて `docs/images/` に保存
7. READMEで画像が表示されることを確認

## 撮影のコツ

- READMEでは小さく表示されるため、文字が詰まりすぎない画面を選ぶ
- 診断結果は「おすすめ構成」「想定導線」「予約導線」が見える位置で撮る
- 管理画面は保存先、Slack、LIFF、回答一覧が伝わる位置で撮る
- スタッフ画面はポイント付与や来店処理の意図が分かる状態で撮る
- LINE導線説明はリッチメニュー風プレビューが見える位置で撮る
