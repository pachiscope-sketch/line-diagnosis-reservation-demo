# ポートフォリオ説明文

このポートフォリオは、LINE公式アカウントを活用した「診断、予約、通知、会員証、管理画面」までの顧客導線を見せるためのデモアプリです。

LIFFアプリとして動く構成を用意しており、LINE User IDと表示名を取得できる場合は、診断回答、予約情報、QR会員証にひもづけられます。LIFF IDが未設定の場合でも、モックユーザーでブラウザ確認できます。

デモは3パターンあります。

- 店舗向け: 来店予約、クーポン、QR会員証、ポイントカード、リピート促進
- 美容室向け: 髪の悩み診断、おすすめメニュー提案、予約、再来店促進
- スクール向け: 講座診断、無料相談予約、資料請求、見込み客管理

予約送信時にはSlack Incoming Webhookへ通知できます。Webhook URLが未設定の場合はモック通知として動くため、営業デモ中にエラーで止まりません。

Supabaseを設定すると、診断回答、予約情報、会員情報をDBへ保存できます。未設定の場合は、ローカルストレージとモックデータで管理画面を確認できます。

また、QR会員証デモでは、会員番号、表示名、ポイント、来店回数、QRコード、最終来店日を表示し、来店スタンプを追加できます。店舗DX、ポイントカード、来店管理案件にも応募しやすい内容です。

単なる技術デモではなく、発注者が「自分の事業でも使えそう」と感じられるよう、集客、予約、会員化、再来店促進の流れとして設計しています。
