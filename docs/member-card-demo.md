# QR会員証デモ

`/member-card` では、LINE User IDまたはモックユーザーIDを使ってユーザー向けQR会員証を表示します。

店舗スタッフ向けの来店処理は `/staff` に分けています。

## 表示内容

- 会員番号
- LINE表示名
- ポイント
- 来店回数
- QRコード
- 最終来店日
- スタッフ向け来店処理画面への導線

## 3画面構成

- ユーザー画面: `/member-card`
- スタッフ画面: `/staff`
- 管理画面: `/admin`

この3画面を分けることで、発注者に「お客様が見る画面」「現場スタッフが使う画面」「管理者が確認する画面」を説明しやすくしています。

## 応募時の説明文

LINE公式アカウント上で会員証・ポイントカード・来店管理を実装できます。

紙のポイントカードをLINE内に置き換えることで、ユーザーはカードを忘れず、店舗側は来店履歴やポイントをデータとして管理できます。

このデモでは、LINE User IDを会員情報にひもづけ、QRコード、ポイント、来店回数を表示しています。スタッフがQRを読み取った後に来店処理を行う画面もモックで用意しているため、店舗・美容室・整体・スクールの会員管理案件に展開できます。

## 実案件での拡張案

- ポイント付与ルール
- 会員ランク
- 誕生日クーポン
- 休眠顧客への再来店通知
- 回数券
- スタッフ用QR読み取り画面
- 管理者ログイン
- SupabaseやCRMへの保存
