# 3パターンデモ

このポートフォリオでは、同じLIFF基盤を3つの業種向けに切り替えて見せられます。

## A. 店舗向けデモ

目的:

- 来店予約
- クーポン配布
- 会員証
- ポイントカード
- リピート促進

導線:

```text
LINE登録 → 来店目的選択 → クーポン表示 → 予約 → 会員証表示 → Slack通知
```

URL:

```text
/?demo=store
```

応募時の見せ方:

店舗DX、LINE会員証、ポイントカード、再来店促進、クーポン施策の案件に向いています。

## B. 美容室向けデモ

目的:

- 髪の悩み診断
- おすすめメニュー提案
- 予約率向上
- 再来店促進

導線:

```text
LINE登録 → 髪の悩み診断 → おすすめメニュー表示 → 予約 → 来店後ポイント付与
```

質問例:

- 髪の悩みは？
- 希望メニューは？
- 希望するLINE機能は？

URL:

```text
/?demo=beauty
```

応募時の見せ方:

美容室、サロン、エステ、ネイルなど、予約率改善と再来店促進を求める案件に向いています。

## C. スクール向けデモ

目的:

- 講座診断
- 無料相談予約
- 資料請求
- 見込み客管理

導線:

```text
LINE登録 → 学習目的診断 → おすすめ講座表示 → 無料相談予約 → 管理者通知
```

質問例:

- 学びたい目的は？
- 希望スタイルは？
- 希望する機能は？

URL:

```text
/?demo=school
```

応募時の見せ方:

スクール、オンライン講座、資格講座、セミナー運営者など、見込み客管理と無料相談予約を増やしたい案件に向いています。
