# 発注者向け デモ説明台本

## 1. 導入

本日は、LINE公式アカウント登録後に、診断、予約、通知、会員証、管理画面までつなげるデモをご覧いただきます。

このデモは、店舗、美容室、スクールの3パターンに切り替えられます。御社の業種に近い形で、LINEをどのように集客や予約に使えるか確認できます。

## 2. トップ画面

最初に、デモパターンを選べます。

店舗向けであれば、クーポン、予約、会員証、ポイントカード。美容室向けであれば、髪のお悩み診断とメニュー提案。スクール向けであれば、講座診断と無料相談予約を想定しています。

## 3. LIFFとLINE User ID

実案件では、この画面をLINE内ブラウザで開きます。

LIFF IDを設定すると、LINEログイン済みのユーザーから表示名やLINE User IDを取得できます。この情報を診断回答、予約、会員証にひもづけることで、誰がどの内容で問い合わせたかを管理できます。

このデモでは、LIFF未設定でもモックユーザーとして動くため、ブラウザだけで確認できます。

## 4. 診断フォーム

ユーザーは選択式で質問に回答します。

長い文章を入力させるのではなく、目的や悩みを短時間で選んでもらうことで、予約や相談まで進みやすくします。

## 5. 診断結果

回答後に、おすすめ導線、必要機能、導入メリット、概算プランが表示されます。

発注者様向けには、ここで「このLINE導線を入れると予約率や問い合わせ率がどう改善できるか」を説明できます。

## 6. 予約フォームとSlack通知

診断結果から予約フォームへ進みます。

送信すると、Slack Webhookが設定されている場合は管理者に通知されます。未設定の場合でもモック通知として動くため、デモ中に止まりません。

## 7. QR会員証

次にQR会員証です。

LINE User IDにひもづいた会員番号、ポイント、来店回数、QRコードを表示します。来店スタンプを追加すると、ポイントと来店回数が増えます。

店舗、美容室、整体などでは、紙のポイントカードをLINE内に置き換える提案ができます。

## 8. リッチメニュー導線

リッチメニューからLIFFへ遷移する説明ページもあります。

「友だち追加 → あいさつメッセージ → リッチメニュー → LIFF診断 → 予約 → 通知 → 管理画面」という流れを、非エンジニアにも分かりやすく説明できます。

## 9. 管理画面

管理画面では、診断回答、予約、会員情報、業種別件数、目的別件数、デモ種別ごとの件数を確認できます。

Supabaseが設定されていればDBデータを表示し、未設定の場合はローカルまたはモックデータを表示します。

## 10. 締め

このように、LINE公式アカウントを単なる配信ツールではなく、診断、予約、通知、会員証、顧客管理までつながる仕組みとして設計できます。

御社の場合は、現在の課題や増やしたい成果に合わせて、設問内容、予約導線、通知先、管理画面、会員証機能を調整して構築できます。
