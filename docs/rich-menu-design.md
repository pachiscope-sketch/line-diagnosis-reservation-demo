# リッチメニューデザイン案

LINE公式アカウントのリッチメニューに設定する6分割案です。

このデモでは `/line-flow` にHTML/CSSのリッチメニュー風プレビューを用意しています。実案件では、Canva、Figma、Photoshopなどで画像を作り、各領域にリンクを設定します。

## 推奨サイズ

LINEリッチメニューの大サイズ例:

```text
2500 x 1686 px
```

小サイズ例:

```text
2500 x 843 px
```

このポートフォリオでは、6分割で機能を見せやすい大サイズを想定します。

## 6分割メニュー案

| 位置 | ボタン文言 | リンク先 | 用途 |
| --- | --- | --- | --- |
| 左上 | 診断する | `https://liff.line.me/{診断用LIFF_ID}` | 主要導線。診断フォームへ誘導 |
| 中上 | 店舗デモ | `https://liff.line.me/{店舗用LIFF_ID}` | 来店予約、クーポン、会員証の提案 |
| 右上 | 美容室デモ | `https://liff.line.me/{美容室用LIFF_ID}` | 髪のお悩み診断、予約率改善の提案 |
| 左下 | スクールデモ | `https://liff.line.me/{スクール用LIFF_ID}` | 講座診断、無料相談予約の提案 |
| 中下 | 会員証 | `https://liff.line.me/{会員証用LIFF_ID}` | QR会員証、ポイントカード、来店管理 |
| 右下 | 導線説明 | `https://your-project.vercel.app/line-flow` | 発注者向けに全体の流れを説明 |

## デザイン方針

- LINEらしい緑をアクセントにする
- 文字は大きめ、短く、非エンジニアにも分かる表現にする
- 「診断」「予約」「会員証」など行動が明確な言葉を使う
- 小さな説明文を詰め込みすぎない
- 店舗、美容室、スクールなど業種別ボタンはアイコンや写真で見分けやすくする
- スマホ画面下部で見ても押しやすい余白を確保する

## 発注者への説明文

リッチメニューは、LINE公式アカウントの画面下部に常時表示できるメニューです。

ここから診断、予約、会員証、クーポンへ直接誘導できるため、メッセージ配信だけに頼らず、ユーザーが自分のタイミングで行動できます。

LIFFアプリと連携すると、LINE User IDを使って診断回答、予約、会員証、ポイント情報をひもづけられます。
